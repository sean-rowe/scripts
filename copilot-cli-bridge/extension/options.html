Copilot CLI Bridge

A plain bridge: when Copilot outputs a command block, it runs on your machine and the output is pasted back. Behaviour options are in the toolbar popup.

How it triggers

The bridge runs any code block whose first line is the marker (default #!run):

```
#!run
git status
```

Tell Copilot once, so you just talk in plain English and it emits the blocks:

When you want to run a shell command on my machine, output ONLY a fenced code
block whose first line is exactly:
    #!run
followed by the command. I'll paste the output back.

Config (optional)

~/.copilot-cli-bridge/config.json — the bridge runs everything by default:

{
  "cwd": "/Users/srowe/Projects",   // working directory for commands
  "timeoutMs": 120000,
  "maxOutputBytes": 1000000,
  "deny": []                        // optional substrings to block; empty = no limits
}

A log of what ran is at ~/.copilot-cli-bridge/bridge.log.
